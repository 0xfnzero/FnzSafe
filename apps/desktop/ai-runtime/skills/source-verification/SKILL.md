# Source Verification

Prefer primary sources for existence and announcement facts, then use independent market sources for adoption and pricing claims. Record the publication or retrieval date. Resolve naming ambiguity before drawing conclusions, especially for chains, tickers, and similarly named projects.

If sources disagree, show the disagreement and avoid selecting the more exciting claim without evidence. Never cite search snippets as final proof when the underlying page can be fetched. Clearly label stale, partial, paywalled, login-only, or unavailable data.
